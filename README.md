
2. **Navigate to the project folder**
   ```bash

   ```

3. **Open any project** by double-clicking the `.html` file, or right-clicking and selecting **"Open with Browser"**

## 📌 Project Details

---

### 1. 🧮 Calculator — `claculator.html`

A simple arithmetic calculator built using HTML forms and inline JavaScript.

**Features:**
- Addition, Subtraction, Multiplication, Division
- Decimal point support
- **AC** — Clears the entire display
- **DC** — Deletes the last character (backspace)
- **^** — Squares the current value
- **=** — Evaluates the expression

**How to use:**
1. Open `claculator.html` in your browser
2. Click number and operator buttons to form an expression
3. Press `=` to get the result
4. Press `AC` to reset

---

### 2. 📋 Student Form — `guess.html`

A student registration form that collects and displays student data in a table.

**Features:**
- Input fields: Name, Age, Gender, Course, Email
- Course selection dropdown (CSS, HTML, JS)
- Data displayed in a results table below the form

**How to use:**
1. Open `guess.html` in your browser
2. Fill in your details in the form
3. Click **Save** to add the data to the table

---

### 3. ✅ To-Do List — `todolist.html`

A task management app that lets you add and track your daily tasks.

**Features:**
- Add new tasks via a text input
- Tasks displayed as a list with checkboxes
- Mark tasks as complete / incomplete
- Delete tasks with a clear button

**How to use:**
1. Open `todolist.html` in your browser
2. Type your task in the input box
3. Click **Add** to add it to the list
4. Click on a task to mark it as done
5. Click the delete icon to remove a task

**Files used:** `todolist.html`, `todolist.css`, `todo.js`

---

### 4. ❓ Quiz App — `quize.html`

An interactive multiple-choice quiz app.

**Features:**
- Displays one question at a time
- Three answer options per question
- Navigate through questions with the **Next** button

**How to use:**
1. Open `quize.html` in your browser
2. Read the question displayed on screen
3. Click one of the answer buttons
4. Click **Next** to move to the next question

**Files used:** `quize.html`, `quize.css`, `quize.js`

---

### 5. 💬 Popup Message — `popup.html`

A simple interactive popup/modal triggered by a submit button.

**Features:**
- Click the **Submit** button to show a popup
- Popup displays a success message with a tick icon
- Click **OK** to close the popup

**How to use:**
1. Open `popup.html` in your browser
2. Click the **Submit** button
3. A popup with "Thank You..!" message will appear
4. Click **OK** to dismiss it

**Files used:** `popup.html`, `popup.css`

---

### 6. 🌤️ Weather App — `images/weather.html`

A live weather application using the **OpenWeatherMap API**.

**Features:**
- Search weather by city name
- Displays temperature (°C), humidity (%), and wind speed
- Dynamic weather icons for: Rain, Clear, Clouds, Drizzle, Mist, Snow

**How to use:**
1. Open `images/weather.html` in your browser
2. Type a **city name** in the search box (e.g., `Chennai`, `London`)
3. Click the 🔍 **Search** button
4. Weather details will be displayed instantly

> ⚠️ **Note:** This app uses the OpenWeatherMap API. If data doesn't load, the API key may need to be refreshed. Get a free key at [openweathermap.org](https://openweathermap.org/api).

**Files used:** `images/weather.html`, `images/weather.css`
